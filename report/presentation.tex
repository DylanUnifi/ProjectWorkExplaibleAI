\begin{frame}{Context and Motivation}
    \begin{columns}
        \begin{column}{0.5\textwidth}
            \textbf{The "Black Box" Problem}
            \begin{itemize}
                \item Deep learning models (CNNs, ViTs) have opaque decision-making processes.
                \item \textbf{Post-Hoc XAI}: Explainers applied \textit{after} training (SHAP, LIME).
                \item \textbf{Intrinsic XAI}: Models interpretable by design (ProtoPNet).
            \end{itemize}

\begin{frame}{Rank Agreement: Total Disagreement}
    \begin{columns}
        \begin{column}{0.4\textwidth}
            \begin{itemize}
                \item Rank correlation is \textbf{negative} (-0.09 for CLE4EVR, -0.24 for MNMath).
                \item Post-hoc methods provide edge-aligned explanations...
                \item ...but they misrepresent the actual broad spatial reasoning of the network!

\begin{frame}{Conclusion}
    \begin{block}{Key Takeaways}
        \begin{itemize}
            \item Relying strictly on "Localization Accuracy" is dangerous: it assumes networks reason using human-defined object boundaries.
            \item Intrinsic interpretability reveals that models learn broad spatial contexts, unlike what post-hoc methods suggest.
        \end{itemize}
    \end{block}
